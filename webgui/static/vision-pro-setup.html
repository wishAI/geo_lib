VISION PRO / LOCAL WI-FI

无需 Tailscale，直接用 Safari 录制

Vision Pro 和这台电脑连接同一 Wi-Fi。只需首次安装并信任本站证书；不需要 Teleop App、VPN 或账户。

正在检查局域网 HTTPS…

  1. 下载证书描述文件
    用 Vision Pro 的 Safari 打开本页，点下面的下载按钮并允许下载。
    下载本站证书
  2. 在设置里安装
    打开「设置」中的「已下载描述文件」，或「通用 → VPN 与设备管理」，安装 Geo Library 局域网 HTTPS。这个文件只包含本站根证书，不配置 VPN 或设备管理。
  3. 开启证书信任
    「设置 → 通用 → 关于本机 → 证书信任设置」，为 Geo Library LAN Root 开启完全信任。
  4. 回到 Safari 开始录制
    打开下面的 HTTPS 入口，点击「进入 Vision Pro」，允许沉浸体验和手部追踪，再使用场景内的 Record / Stop。
    打开 AVP 动作工作台

HTTP 页面只能预览和回放。Safari 要求受信任的 HTTPS 才能采集头部和双手；跳过证书警告不能替代信任设置。安装后不需要重复操作。
